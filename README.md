PrTrx PT1 便携式QRP SDR短波电台 开源项目说明
 
一、项目简介
1. PrTrx PT1 是一款紧凑型便携式 QRP SDR 架构业余无线电收发电台。本项目为硬件完全开源、软件闭源授权 的准商业开源项目。部分硬件与软件设计参考源自 VK7IAN 开源项目 MBPTRX，且已获得 VK7IAN 正式授权，允许基于 MBPTRX 架构进行二次开发，并允许将部分衍生软件源码进行闭源商用化落地使用。
2. PrTrx PT1 基于 Raspberry Pi Pico2（RP2350）主控的QSD正交采样检波 + QSE正交调制发射 SDR架构。频率覆盖3.5MHz - 30MHz业余无线电短波波段；具备SSB、CW、AM、FM模式；28KHz频谱和瀑布图、降噪NR、噪声消隐NB、陷波Notch滤波器；2.0寸320*240分辨率高清IPS液晶显示屏；

四、制作难度与适配人群

本项目属于中高阶硬核硬件DIY项目，电路结构、射频匹配、贴片焊接、参数调试要求较高：
- 不适合新手入门练习；
- 强烈建议具备扎实的模电、射频理论基础，且焊接、硬件调试动手能力极强，并有相关测试仪器的的资深爱好者制作；
- 新手请勿盲目复刻，避免器件浪费、设备无法正常工作。

五、软件、硬件性能限制

1. 为了获取更低的噪音，硬件采用LDO稳压，所以发热高于DC-DC。
2. 为了获取更高的IMD性能，硬件设计限制了发射功率，在10W PEP输出功率下可获得优于-35dBc的IMD3性能（实测为-38dBc）。
3. 为了获取准确的信号强度，低于-120dBm的信号使用多次平均，所以低于-120dBm的信号dBm值显示速度变慢，但低于-130dBm的信号强度仍然难以准确显示。
4. 因为体积限制，散热性能并不出众，在无外部辅助散热的情况下，不建议FT8模式下超过5W使用；如果是常规通联可以放心使用在10W。
5. FM采用相位解调，轻微的相位抖动就会抬高噪声，在使用4Ω/2W扬声器时会造成电源抖动导致相位抖动，本底噪声会抬高2-3dB，所以建议使用8Ω/1W扬声器。
