协处理器ch32v203接口库，用于编写自己的PT1程序。


注意EEPROM安全使用边界

| 地址范围 | 用途 | 第三方固件处理 |
|---|---|---|
| `0x000-0x2FF` | 普通用户设置 | 可以按公开接口使用，但不要整片擦除 |
| `0x300-0x354` | TCXO、RSSI、RX/TX IQ、功率、电压、分波段 RSSI 等工程校准 | 必须保留 |
| `0x355-0x5BF` | 当前预留区 | 不要擦除，可作为第三方私有数据区，但必须自行划分和加标记 |
| `0x5C0-0x5FF` | 呼号 A/B 配置 | 必须保留 |
| `0x600-0x6FF` | 授权槽 A | 必须保留，不能写入 |
| `0x700-0x7FF` | 授权槽 B | 必须保留，不能写入 |
